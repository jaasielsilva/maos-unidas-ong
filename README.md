# Mãos Unidas – Plataforma web para ONGs

Projeto acadêmico (Uso de Design) com HTML5, CSS3 responsivo e JavaScript.

## 👉 Ver a aplicação funcionando

**Clique aqui: https://jaasielsilva.github.io/maos-unidas-ong/**

Não precisa instalar nada. Também é possível clicar no link do site em **About**, no canto direito desta página.

## Páginas
- [Início](https://jaasielsilva.github.io/maos-unidas-ong/)
- [Projetos](https://jaasielsilva.github.io/maos-unidas-ong/projetos.html)
- [Cadastro](https://jaasielsilva.github.io/maos-unidas-ong/cadastro.html)

## Estrutura
```
index.html, projetos.html, cadastro.html
css/   variables, base, components, layout, responsive (módulos importados por style.css)
js/    main.js (menu, máscaras, validação, toasts e modal)
img/   imagens em WebP e JPG
```
